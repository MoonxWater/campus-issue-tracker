# Campus Issue Tracker

## Description

A small full-stack web application for reporting and tracking campus issues.

## Tech Stack

* React
* Vite
* Node.js
* Express
* MongoDB
* Git/GitHub

## Project Structure

```text
frontend → React application
backend  → Express API
```

## Running the Project

To start the frontend, run the following command in the root directory:
```bash
npm run start:frontend
```
Or navigate to the `frontend/` directory and run `npm run dev`.

To start the backend, run the following command in the root directory:
```bash
npm run start:backend
```
Or navigate to the `backend/` directory and run `npm start`.
